How the Model Works

Token Radar computes the implied token value of pre-token protocols using a robust quantitative framework: Implied Value = TVL × Category Multiple × Growth Multiplier (7d) × Maturity Multiplier (Age). Category multiples are derived from the median market-cap-to-TVL ratios of tokened protocols per category (clamped between 0.05 and 3.0). Growth is clamped between -60% and +120% with a 0.5 weight. Maturity is scaled from protocol age without a token (capped at 1,095 days).
